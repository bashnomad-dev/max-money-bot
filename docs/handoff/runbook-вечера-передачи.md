# Runbook вечера передачи (для вендора)

Линейный сценарий передачи на инстанс Евгения. Технические детали — в [../../RUNBOOK.md](../../RUNBOOK.md),
полный разбор «что у кого» — в [../handover-checklist.md](../handover-checklist.md).

Бот вендора (`Finans_stroy_bot`) Евгению **не отдаём** — сначала демонстрируем на нём,
затем поднимаем **отдельный инстанс на его данных**.

---

## Заранее (за 2–3 дня, делает Евгений по гайдам)
- [ ] **Бот в MAX** заведён на его ООО через business.max.ru/self, прошёл модерацию (до 2 раб. дней),
      токен из «Интеграция» прислан — `MAX_BOT_TOKEN`. Гайд: «Как создать MAX-бота».
- [ ] **Google-таблица** создана (пустая) и расшарена Редактором на `bot-max-money@maxmoneybot.iam.gserviceaccount.com`,
      ссылка прислана. Гайд: «Создать и расшарить Google-таблицу».
- [ ] **Параметры** подтверждены: точки (Зинино/Кармалы), порог крупной суммы (150000), нужен ли PIN.

> Без токена и таблицы боевой прогон вечером не состоится. Это блокеры — проверить ДО встречи.

## Вечер передачи (сессия ~1 час, делаем вместе)

1. **Ключи в `.env` инстанса** (через веб-консоль Timeweb VNC, SSH с домашней сети не работает):
   - [ ] `MAX_BOT_TOKEN` Евгения.
   - [ ] `OPENROUTER_API_KEY` (+ `OPENROUTER_MODEL=anthropic/claude-haiku-4.5`).
   - [ ] `secrets/service-account.json` на месте (тот же сервисный аккаунт, что расшарен в таблицу).
   - [ ] `DEFAULT_SHEET_ID` = ID таблицы Евгения.
   - [ ] Параметры: `DEFAULT_LOCATION`, `LARGE_AMOUNT_THRESHOLD_RUB`, `OPS_PIN` (если решили).
   - [ ] `chmod 600 .env secrets/service-account.json`.

2. **Поймать user_id и дать доступ:**
   - [ ] Евгений пишет боту «старт» → ловим его id в `journalctl -u maxbot` → в `ALLOWED_USER_IDS` → `systemctl restart maxbot`.
   - [ ] Бот ответил приветствием — доступ есть.

3. **Подключить таблицу и залить прайс:**
   - [ ] `/привязать <sheet_id>` → `/настройка` → импорт ~4900 SKU в чистую таблицу.

4. **Боевой прогон (реальные слова Евгения):**
   - [ ] Продажа, закупка, возврат, расход, `/остаток`, «отчёт за месяц» — по одной операции.
   - [ ] Проверить голосовой ввод (GigaAM + ffmpeg на VPS).
   - [ ] По ходу добавить алиасы частых товаров в лист «Товары», чтобы бот не переспрашивал.

5. **Обучение и закрытие:**
   - [ ] Показать `/отмени`, `/правка`, `/пересчёт`, `/сегодня`; правило «одна операция за раз».
   - [ ] Отдать памятку [evgeny-guide / onboarding-чеклист].
   - [ ] Закрыть деньги: разовый запуск + абонентка (предложение на руки).

## После передачи
- [ ] Проверить, что вечерний автоотчёт (21:00) пришёл.
- [ ] Убедиться, что cron-бэкап Sheets настроен (см. RUNBOOK §«Бэкап Sheets»).
