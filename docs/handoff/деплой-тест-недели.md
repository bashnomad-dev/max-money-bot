# Запрос штабу: деплой тест-недельной версии (Евгений)

**Что:** выкатить ветку `fix/demo-stt-parsing` (коммит `012a95a`) на VPS, где уже крутится бот.
**Зачем:** упрощения под тест-неделю Евгения по фидбэку ДЕМО (записная книжка) + многопользователь.
**Решение по деплою — за штабом** (бриф). Доступ к VPS есть.

## Что меняется в поведении
- Остатки выключены, каталог не принуждаем, автоотчёт 21:00 выключен.
- Точка по умолчанию = Магазин Зинино (не переспрашивает).
- Few-shot на фразах ДЕМО, лучшая догадка вместо допросов.
- Колонка «Автор» (MAX user_id) в листах.
- Авто-фолбэк STT.
- 105 тестов зелёные.

## Команды на сервере
```
cd <папка_проекта>
git fetch && git checkout fix/demo-stt-parsing && git pull
printf '\nENABLE_STOCK_TRACKING=false\nENFORCE_PRODUCT_CANONICALIZATION=false\nDAILY_REPORT_ENABLED=false\n' >> .env
systemctl restart <имя_сервиса_бота>
```
Новых зависимостей нет — `pip install` не требуется.

## После рестарта
- Один раз отправить боту `/setup` — добавит колонку «Автор» в существующую таблицу (миграция в коде).
- Таблица и доступ Евгения — те же, что на ДЕМО.

## Откат
```
git checkout <предыдущая_ветка_или_коммит>
# убрать 3 флага из .env (или оставить — на старом коде игнорируются)
systemctl restart <имя_сервиса_бота>
```
