# Проектная документация — max-money-bot

Голосовой бот в MAX для владельца розничного магазина стройматериалов. Голосом фиксируешь продажи, закупки, возвраты, расходы, списания, перемещения — бот пишет в Google-таблицу (Деньги + Товары + Остатки), автоматически пересчитывает остатки, шлёт текстовый автоотчёт в 21:00, отвечает голосом на запросы вроде «сколько ГКЛ на складе».

## Контекст бизнеса (TL;DR)

Владелец розничного магазина стройматериалов с несколькими точками продаж и/или складами. В течение дня надиктовывает в MAX операции:

- **Продажа:** «Продал 10 листов ГКЛ за 5 тысяч наличными» → деньги + товары + остатки в одной транзакции.
- **Закупка:** «Получил от Петровича 100 мешков штукатурки за 25 тысяч безналом» → деньги + товары + остатки + пересчёт средневзвешенной цены.
- **Возвраты:** «Возврат: вернули 2 листа ГКЛ, отдал тысячу» → деньги + товары + остатки.
- **Списание:** «Списал 3 мешка штукатурки, бой» → товары + остатки.
- **Перемещение:** «Перевёз 20 листов ГКЛ со склада на магазин на Ленина».
- **Расход без товара:** «Заплатил аренду 80 тысяч на счёт».
- **Запросы:** «Сколько ГКЛ на складе?», «Отчёт за месяц по прибыли».
- **Инвентаризация:** `/inventory` с диалогом сверки факт-расчёт.

Главная ценность: операции попадают в учёт сразу голосом, без касания таблицы; остатки всегда расчётные и точные; в 21:00 — текстовый итог дня.

## Ключевые архитектурные решения

- **Sheets — единственный источник правды.** SQLite — только технический слой.
- **Транзакционность через `tx_id`:** связанные записи в Деньгах и Товарах + пересчёт Остатков пишутся атомарно с компенсацией при сбое.
- **Лист «Остатки» расчётный** — обновляется только ботом. Для корректировки факта — `/inventory`.
- **Канонизация товаров и точек** через справочные листы — без неё топ-3 и поиск остатков по товару врут.
- **Гибридный UX:** high confidence → запись сразу; крупная сумма / новый товар / новая точка → карточка; low confidence → уточнение.
- **Эволюция колонок:** клиент добавляет свои колонки справа от ботовских — бот их не трогает. Системные изменения схемы — через обновление кода.
